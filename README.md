# Zebra Wars

A browser game for patients 13 and older with rare immune diseases. For the
initial CGD games, you make choices for a week at a time, then command your
immune cells in a battle against whatever organisms came home with you. Our
games start with chronic granulomatous disease (CGD), X-linked and autosomal
recessive.

This is a beta. The medical content has not had clinical review yet, and the
epilogue is marked as a draft.

For developer information (running, checking, deploying), see [docs/dev.md](docs/dev.md).
