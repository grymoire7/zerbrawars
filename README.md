# Zebra Wars

A browser game for patients 13 and older with rare immune diseases. You live a week, then command your immune cells in a turn-based fight against what came home with you. It starts with chronic granulomatous disease (CGD), X-linked and autosomal recessive.

This is a beta. The medical content has not had clinical review yet, and the epilogue is marked as a draft.

For developer information (running, checking, deploying), see [docs/dev.md](docs/dev.md).
